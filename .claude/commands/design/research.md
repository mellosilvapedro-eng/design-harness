Research: **$ARGUMENTS**

Resolve the context. Follow `memory/INDEX.md` for anything already known, including
whether this was researched before.

Dispatch `design-researcher` with the problem, the context name and file path, the
project folder if any, and the memory paths to read.

Then load `research-synthesis` and write `projects/<slug>/research.md` yourself. The
agent's report is input. Carry its mode line into the file: a fallback run is a
limitation that belongs on the page, not only in the chat.
